# 深度学习训练基础

> [!abstract] 核心结论
> 深度学习训练把模型视为带参数的复合函数：前向计算得到预测，用损失衡量预测与目标的差异，反向传播计算梯度，优化器再更新参数。阅读任何模型代码时，优先追踪张量 Shape、可学习参数、计算图和训练/推理差异。

## 从张量和线性层开始

大模型中的计算最终都落在张量运算上。常用记号为：

| 符号 | 含义 |
| --- | --- |
| $B$ | batch size |
| $T$ | 序列长度 |
| $D$ | 隐藏维度 |
| $V$ | 词表大小 |

`nn.Linear(D_in, D_out)` 对输入最后一维做仿射变换。采用批量行向量约定：

$$
Y=XW^{\mathsf T}+b
$$

```text
X       [B, D_in]           或 [B, T, D_in]
weight  [D_out, D_in]
bias    [D_out]
Y       [B, D_out]          或 [B, T, D_out]
```

参数量为 $D_{out}D_{in}+D_{out}$。线性层保留前导维，只替换最后一维，因此可以直接作用于 Transformer 的 `[B,T,D]`。

> [!tip] Shape 检查法
> 对每一步写出输入、参数和输出 Shape，先检查矩阵乘法的内维是否相等，再检查广播发生在哪些维度。Shape 正确不能证明语义正确，但能快速排除大量实现错误。

## 前向、损失、反向与更新

一个训练 step 的职责链是：

```text
batch
→ forward：由当前参数计算输出
→ loss：把输出和目标归约为标量
→ zero_grad：清除上一轮累积梯度
→ backward：沿计算图应用链式法则
→ step：优化器真正修改参数
```

梯度给出损失局部增长最快的方向，基础梯度下降沿反方向更新：

$$
\theta\leftarrow\theta-\eta\nabla_\theta L
$$

若 $O=XW^{\mathsf T}+b$，上游梯度 $G=\partial L/\partial O$，则：

$$
\frac{\partial L}{\partial W}=G^{\mathsf T}X,\qquad
\frac{\partial L}{\partial b}=\sum_{i=1}^{B}G_i,\qquad
\frac{\partial L}{\partial X}=GW
$$

每个参数梯度的 Shape 必须与参数本身相同。自动微分框架通常计算向量—雅可比积，而不是显式构造完整 Jacobian；非标量输出调用 `backward()` 时，需要先归约成标量或显式提供上游梯度。

## Softmax 与交叉熵

分类头输出的是 logits，即未归一化分数：

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

单标签交叉熵为：

$$
L=-\log p_y=-z_y+\log\sum_j e^{z_j}
$$

对单个样本，交叉熵对 logits 的梯度为 $p-y_{onehot}$。这揭示了训练信号：提高正确类别的 logit，同时按当前概率压低其他类别。

实现中使用 LogSumExp，并在指数运算前减去最大 logit 以改善数值稳定性。`nn.CrossEntropyLoss` 应直接接收 logits，不要先手动 Softmax。`reduction='none'` 控制如何聚合样本损失，与数值稳定性无关。

## 非线性与稳定训练

若层间没有非线性，多层线性变换仍可合并成一个线性变换。常见激活包括 ReLU、GELU 和 SiLU；选择时需要同时考虑表达能力、梯度和数值特性。

| 方法 | 主要作用 | 边界 |
| --- | --- | --- |
| Xavier / He 初始化 | 让前向激活和反向梯度的尺度不过快放大或衰减 | 应结合激活函数，参数不是越小越好 |
| 梯度裁剪 | 限制异常大的梯度范数 | 缓解梯度爆炸，不解决梯度消失 |
| Weight decay | 在更新中限制参数尺度 | AdamW 的解耦衰减不等同于简单 L2 loss |
| Dropout | 训练时随机屏蔽激活 | 推理时关闭，不减少参数量 |
| 归一化与残差 | 稳定尺度并保留信息/梯度通路 | 在 Transformer 中的具体位置见 [[Transformer]] |

## 泛化与数据划分

- **欠拟合**：训练误差和验证误差都高，可能是模型、特征、训练时间或优化过程不足。
- **过拟合**：训练误差继续下降，验证误差恶化或两者差距持续扩大。
- **泛化误差**：未知真实分布上的期望误差；测试误差只是有限样本估计。
- **泛化间隙**：训练表现与验证/测试表现的差异，不等同于泛化误差本身。

不能用训练 loss 单独判断泛化。验证集用于选择模型和超参数，测试集应在决策结束后用于最终估计；完整评测方法见 [[大模型评测]]。

## 最小训练循环

```python
model.train()
for x, y in train_loader:
    x, y = x.to(device), y.to(device)
    logits = model(x)
    loss = loss_fn(logits, y)

    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)  # 按需
    optimizer.step()
```

这里 `forward()` 只产生输出，`backward()` 只计算并累积梯度，`optimizer.step()` 才更新参数。`torch.no_grad()` 仅禁止记录新的计算图，不会清除已有 `.grad`，也不会自动切换模块的训练/评测模式。

## 易错点

> [!warning] 训练代码能运行不代表训练逻辑正确
> 最常见的隐蔽错误包括：忘记清梯度、把概率而非 logits 传给交叉熵、在错误维度 Softmax、验证时仍启用 Dropout，以及对大小不同的 batch 直接平均 batch mean。指标应按有效样本数或有效 token 数加权汇总。
