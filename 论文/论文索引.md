# 论文索引

> [!abstract] 定位
> 单篇论文笔记用于保存论文的论点、方法、证据和局限；主干概念页保存跨来源验证后的稳定知识。论文不是第七个知识领域，而是连接六个领域的证据层。

## 使用规则

- 文件命名采用 `年份-简称.md`，例如 `2017-Transformer.md`。
- 新建时复制 [[_论文分析模板]]，用“属于”返回本页；只链接论文实际涉及的概念。
- 先忠实记录论文做了什么，再明确区分论文结论、个人推断和待复现实验。
- 只有经过理解和核验的稳定结论才回写概念页；概念页引用本论文，避免复制整段正文。
- 综述或多论文比较可建立专题页，但仍需为关键单篇保留来源入口。

## 阅读状态

| 状态 | 含义 |
| --- | --- |
| 待读 | 已收录，尚未开始 |
| 粗读 | 已理解问题与主要贡献 |
| 精读 | 已核对方法、实验与局限 |
| 复现 | 已运行代码或完成关键实验 |
| 已提炼 | 稳定结论已回写主干笔记 |
