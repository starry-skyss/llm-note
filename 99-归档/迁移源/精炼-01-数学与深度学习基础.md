# 数学与深度学习基础（精炼）

> 定位：保留阅读、实现和排查大模型代码时反复使用的基础。重点不是背公式，而是能追踪张量形状，并说清前向、损失、反向传播和参数更新之间的关系。

## 核心要点

- 深度学习模型本质是带可学习参数的复合函数。训练就是用数据定义目标，再通过梯度调整参数。
- 神经网络中的“层”接收张量并输出张量；理解一层时优先问：输入/输出 shape、计算方式、可学习参数、解决的问题、训练与推理是否不同。
- 参数由训练学习，如权重和偏置；超参数由人设定或搜索，如学习率、batch size、层数、隐藏维度和 weight decay。
- `forward()` 只计算输出，`backward()` 只计算梯度，真正修改参数的是 `optimizer.step()`。

## 张量、线性层与形状

常用记号：

| 符号 | 含义 |
| --- | --- |
| `B` | batch size |
| `T` | 序列长度 |
| `D` / `C` | 隐藏维度 |
| `V` | 词表大小 |

对 PyTorch 的线性层 `nn.Linear(D_in, D_out)`：

```text
X       [B, D_in]
weight  [D_out, D_in]
bias    [D_out]
Y       [B, D_out]
```

批量行向量约定下：

$$
Y=XW^\top+b
$$

参数量为 $D_{out}D_{in}+D_{out}$。`Linear` 作用于输入的最后一维，因此也能直接接收 `[B,T,D_in]` 并输出 `[B,T,D_out]`。

形状检查不是证明公式正确，但能快速排除大量错误。矩阵推导前应先写出每个量的 shape，并始终保持行向量或列向量约定一致。

## 梯度与自动微分

梯度给出损失增长最快的局部方向，因此梯度下降沿反方向更新：

$$
\theta \leftarrow \theta-\eta\nabla_\theta L
$$

若 $O=XW^\top+b$，上游梯度为 $G=\partial L/\partial O$，则在上面的 batch 约定下：

$$
\frac{\partial L}{\partial W}=G^\top X,\qquad
\frac{\partial L}{\partial b}=\sum_{b=1}^{B}G_b,\qquad
\frac{\partial L}{\partial X}=GW
$$

需要掌握：

- 反向传播反复应用链式法则；框架实际计算的是向量-雅可比积，通常不会显式构造完整 Jacobian。
- 参数梯度的 shape 与参数本身相同。
- PyTorch 默认累积 `.grad`，所以每轮更新前需要清梯度。
- 标量可直接调用 `backward()`；非标量输出必须先归约为标量，或传入上游梯度。这不是“不能求导”，而是需要明确要计算哪个向量-雅可比积。
- `torch.no_grad()` 只是暂时不记录计算图，不会删除已有梯度，也不会自动切换模型模式。

## Softmax、交叉熵与数值稳定性

分类模型通常输出 logits，即未归一化分数。Softmax 将其转成概率：

$$
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
$$

单标签交叉熵为：

$$
L=-\log p_y=-z_y+\log\sum_j e^{z_j}
$$

最值得记住的结论：

- 给所有 logits 同减一个常数不改变 Softmax，因此实现中常减去最大 logit，避免指数上溢。
- `log_softmax`/`CrossEntropyLoss` 使用 LogSumExp 形式，避免先得到接近 0 的概率再计算 `log(0)`。
- `nn.CrossEntropyLoss` 应直接接收 logits；训练前不要手动 Softmax。
- 对单个样本，交叉熵对 logits 的梯度是 $p-y_{onehot}$。
- `reduction='none'` 只控制样本损失如何聚合，与数值稳定性无关。训练常用均值，使梯度尺度较少受 batch size 影响。

## 非线性、稳定训练与泛化

若多层之间没有非线性，多个线性层仍等价于一个线性变换。激活函数让网络能拟合非线性关系。

| 方法 | 应掌握的作用 | 关键提醒 |
| --- | --- | --- |
| ReLU | 简单高效，引入非线性 | 负区间梯度为 0，可能出现 dead ReLU |
| GELU | 平滑调节输入幅度 | $x\Phi(x)$，常见于 Transformer |
| SiLU/Swish | 平滑激活 | $x\sigma(x)$；也是 SwiGLU 的门函数 |
| Xavier/He 初始化 | 控制前向与反向的数值尺度 | 应结合激活函数选择，不是越小越好 |
| 梯度裁剪 | 限制异常大的梯度范数 | 主要缓解梯度爆炸，不能解决梯度消失 |
| 残差连接 | 提供恒等信息和梯度路径 | 学习的是对已有表示的修正量 |
| LayerNorm | 稳定单个样本/Token 的特征尺度 | Transformer 中沿最后一维归一化 |

泛化相关概念：

- 欠拟合：训练误差和验证误差都高。
- 过拟合：训练误差继续下降，但验证误差变差或两者差距明显扩大。
- 泛化误差是模型在真实未知分布上的期望误差，测试误差只是它的有限样本估计；泛化误差不等于泛化间隙。
- Weight decay 限制参数尺度；Dropout 在训练时随机屏蔽激活、推理时关闭。二者都不减少模型参数量。
- 对普通 SGD，L2 正则化与特定形式的权重衰减可等价；AdamW 将衰减与自适应梯度更新解耦，不能简单视为把 L2 项塞进 loss 后完全相同。

## 最小可迁移训练代码

```python
model.train()
for x, y in train_loader:
    x, y = x.to(device), y.to(device)
    logits = model(x)
    loss = loss_fn(logits, y)
    optimizer.zero_grad(set_to_none=True)
    loss.backward()
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)  # 按需
    optimizer.step()
```

固定心智模型：

```text
batch → forward → loss → zero_grad → backward → step
```

## 易错点

- `backward()` 不更新参数；`optimizer.step()` 也不会替你清除旧梯度。
- 激活函数通常改变数值而不改变 shape；线性层才负责最后一维的映射。
- 负梯度表示增大参数可能降低损失，因此“减去负梯度”会增大参数。
- 不能通过 loss 数值直接判断泛化；必须看独立验证/测试数据。
- 平均每个 batch 的均值在 batch 大小不一时会产生偏差，应按样本数或有效 token 数加权汇总。
