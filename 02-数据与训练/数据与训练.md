# 数据与训练

> [!abstract] 范围
> 解释原始数据如何变成训练样本，以及模型如何通过目标函数、优化器和分布式训练获得基础能力。

## 边界

- 本页负责数据治理、Tokenizer、预训练目标、训练循环与训练系统。
- 模型内部结构归入“基础与模型”；SFT、偏好优化与能力评测归入“后训练与评测”。
- 在线推理和模型服务归入“推理与 AI Infra”。

## 推荐学习顺序

1. [[Tokenizer]]：token、ID、词表、子词算法和特殊标记
2. [[预训练与样本构造]]：数据管线、输入/标签错位、next-token 目标和切分泄漏
3. 混合精度、梯度累积、Checkpoint 与分布式训练
4. 数据配比、训练稳定性与 Scaling 规律

## 当前知识层级

```text
数据与训练
├─ Tokenizer
└─ 预训练与样本构造
```

- [[Tokenizer]]：文本到离散 ID 的唯一主解释。
- [[预训练与样本构造]]：从 token 数据到自回归训练目标的完整路径。
