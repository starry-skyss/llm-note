# 预训练与样本构造

> [!abstract] 核心结论
> 自回归预训练把连续 token 序列错开一位，要求模型在每个位置根据可见前文预测下一 token。训练信号由原始文本自动构造，但数据切分、mask、packing 和有效 token 统计会直接决定模型究竟学到了什么。

## 从文本到训练 Batch

```text
原始文档
→ 清洗、去重、质量过滤和数据混合
→ [[Tokenizer]] 编码
→ token IDs
→ 添加边界/特殊 token
→ 拼接或 packing
→ 截取长度 T+1
→ 输入 x 与目标 y 错开一位
→ batch [B,T]
```

对片段 `[18,7,4,9,3]`，若上下文长度为 4：

```text
x: [18, 7, 4, 9]
y: [ 7, 4, 9, 3]
```

第 $t$ 个位置贡献“根据当前位置及可见前文预测下一个 token”的目标。若 `x` 与 `y` 相同，模型训练的就不是 next-token prediction。

## Shape 主线

```text
token IDs       [B,T]      整数索引
hidden states   [B,T,D]    每个 token 的上下文表示
logits          [B,T,V]    每个位置对词表的原始分数
targets         [B,T]      正确的下一个 token ID
```

语言模型交叉熵常把序列位置并入样本维：

```text
logits  [B,T,V] → [B*T,V]
targets [B,T]   → [B*T]
```

$V$ 是词表大小，$D$ 是隐藏维，二者不能因数值偶然相同而混用。Embedding 和 LM Head 的模型侧位置见 [[Transformer]]。

## 自回归目标

序列联合概率按链式法则分解为：

$$
p(x_{1:T})=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t})
$$

训练最小化有效 token 的平均负对数似然：

$$
L=-\frac{1}{N_{valid}}\sum_t m_t\log p_\theta(x_t\mid x_{<t})
$$

$m_t\in\{0,1\}$ 是 loss mask。Padding、prompt 中不希望监督的部分或文档拼接边界，可以通过 `ignore_index` 或显式 mask 排除；分母必须使用有效 token 数，而不是盲目使用 $BT$。

预训练属于自监督学习，因为标签由文本右移自动产生。它能学习语言结构、模式和数据中可预测的信息，但“数据中出现过”不等于模型会稳定记住，更不等于回答可验证。

## 最小样本生成

```python
def get_batch(data, batch_size, block_size, device):
    high = len(data) - block_size
    starts = torch.randint(0, high, (batch_size,))
    x = torch.stack([data[i:i + block_size] for i in starts])
    y = torch.stack([data[i + 1:i + block_size + 1] for i in starts])
    return x.to(device), y.to(device)
```

这里随机的是片段起点，`block_size` 只是最大截取长度，不证明模型能有效利用同样长的上下文。真实训练还需处理文档边界、packing、数据并行采样和随机种子恢复。

## Bigram 为什么只是教学模型

字符级 Bigram 可以直接使用 `Embedding(V,V)`：

```text
current token ID [B,T] → next-token logits [B,T,V]
```

它能演示编码、batch、loss、反向传播和生成闭环，但每个位置只根据当前 token 查表。即使输入 Shape 含有 $T$，模型也没有利用更早上下文。Transformer 的关键增量是让每个位置通过因果 Attention 获取可见前文，形成上下文化表示。

## 数据切分与泄漏

- 训练集用于梯度更新，验证集用于模型选择和超参数决策，测试集用于决策结束后的最终估计。
- 应以文档或更高层实体切分，避免同一文档片段跨集合。
- 近重复数据、模板化内容和引用关系可能造成隐性泄漏。
- 时间敏感任务应考虑时间切分，避免训练数据包含评测时点之后的信息。
- Benchmark 出现在预训练语料中会污染能力估计，字符串不完全相同也可能是语义重复。

`batch` 是一次并行处理的样本集合；`step/iteration` 通常对应一次参数更新；`epoch` 是完整遍历训练集一次。大规模随机流式训练常主要按 token 数和 step 计量，不一定有清晰 epoch。

## 易错点

> [!warning] 数据管线错误会伪装成模型问题
> 标签未错位、mask 分母错误、跨文档无边界拼接、验证集进入训练采样器或设备/dtype 不匹配，都可能让 loss 看似正常却训练出错误行为。先用一个极小 batch 打印 IDs、mask、targets 和有效 token 数，再运行大规模训练。

## 掌握要求

- [ ] 能从文本追踪到 `[B,T] → [B,T,D] → [B,T,V]`。
- [ ] 能推导 next-token likelihood 与交叉熵目标。
- [ ] 能构造错开一位的 `x/y`，并正确处理 loss mask。
- [ ] 能解释 Bigram 即使接收序列也没有利用长上下文。
- [ ] 能列出文档泄漏、近重复和评测污染的检查方法。
