# 应用与前沿

> [!abstract] 范围
> 汇总跨模块的应用工程方法和仍在快速演化的研究方向，关注它们如何依赖主干知识，而不是按热点堆积名词。

## 边界

- 本页负责 Prompt、Context、应用架构、工作流、人机协同、多模态和前沿方向。
- 已有明确主归属的底层机制仍写回对应领域，本页只记录应用关系与研究问题。
- 单篇论文的实验与证据进入论文区；经过验证的稳定结论再回写主概念页。

## 推荐学习顺序

1. Prompt、System Prompt、结构化输出与上下文管理
2. Pipeline、Workflow、Framework 与 Harness 的职责边界
3. 质量、时延、成本、安全和用户体验的联合设计
4. 多模态、长上下文与端侧模型
5. 新架构、新训练范式和能力边界
6. 用论文、实验和评测持续更新判断
