# 后训练与评测

> [!abstract] 范围
> 解释如何把预训练模型调整为可用助手，以及如何用可复现证据判断模型与系统是否真正改善。

## 边界

- 本页负责 SFT、参数高效微调、偏好优化、对齐、安全和评测方法。
- 预训练数据与训练基础归入“数据与训练”。
- RAG、Agent 等完整系统的线上效果仍在本页引用评测方法，但系统结构归入“RAG 与 Agent”。

## 推荐学习顺序

1. 训练集、验证集、测试集、指标和基线
2. [[后训练与对齐]]：SFT、偏好数据、Reward Model、RLHF 与 DPO
3. 从后训练页进入参数高效微调，理解 LoRA 与 QLoRA
4. [[大模型评测]]：自动/人工评测、Bad Case、安全、可观测性与发布门槛
