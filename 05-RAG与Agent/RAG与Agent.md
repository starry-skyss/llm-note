# RAG 与 Agent

> [!abstract] 范围
> 解释如何让模型使用外部知识、工具、状态和执行循环，从一次文本生成扩展为可验证的任务系统。

## 边界

- 本页负责检索增强、工具调用、Agent 循环、记忆、协议和多 Agent 协作。
- 模型内部能力归入“基础与模型”，性能与部署归入“推理与 AI Infra”。
- 评测设计归入“后训练与评测”，具体业务产品形态归入“应用与前沿”。

## 推荐学习顺序

1. Embedding 检索、切分、召回、过滤和重排
2. RAG 的索引、检索、生成与引用链路
3. Function Calling、Tool Calling 与结构化输出
4. Agent 的状态、观察、决策、执行与终止条件
5. 短期上下文、长期记忆与上下文压缩
6. MCP、多 Agent、权限边界与失败恢复
